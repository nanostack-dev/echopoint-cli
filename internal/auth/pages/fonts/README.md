# Callback page fonts

These Latin variable WOFF2 subsets are the same Outfit, Plus Jakarta Sans, and Geist Mono files bundled by the Echopoint frontend through Fontsource. They keep the local callback page aligned with `@nanostackorg/design-system` 0.2.2.

The files are unmodified. Their upstream copyright notices and SIL Open Font License files are included here, embedded in the binary, and emitted in the callback HTML source. Font data is inlined into the response because the CLI shuts down its callback server after authentication.

Upstream license sources:

- https://github.com/google/fonts/blob/main/ofl/outfit/OFL.txt
- https://github.com/google/fonts/blob/main/ofl/plusjakartasans/OFL.txt
- https://github.com/google/fonts/blob/main/ofl/geistmono/OFL.txt
